# PostgreSQL learning path

Start with the [roadmap](DATABASE_LEARNING_ROADMAP.md), then use the runnable [database exercises](../../../backend/src/database/exercises/README.md). The exercise folder is the best place to connect concepts to this repository's schema and SQL.

For internals beyond the roadmap, read the [PostgreSQL deep dive](POSTGRESQL_DEEP_DIVE.md), covering MVCC, WAL, indexes, query planning, locks, pooling, vacuum, and partitioning.

## Core materials

- [Quick start](QUICK_START_POSTGRESQL.md) — local concepts and setup orientation. Some original migration examples are historical.
- [Interview exercises](POSTGRESQL_INTERVIEW_EXERCISES.md) — SQL, indexing, transaction, and concurrency practice.
- [Learning summary](learning-summary.md) — a concise topic map; completion claims in older notes are not a skills assessment.
- [Migration guide](POSTGRESQL_MIGRATION_GUIDE.md) — retained as a historical learning scenario, not the current migration procedure.

Operational procedures live under [runbooks](../../RUNBOOKS/README.md), not in this learning path.
